# Curso de Telecomunicaciones de Emergencia

Este es el repositorio oficial del **Curso de Telecomunicaciones de Emergencia**, diseñado para Radioaficionados y Voluntarios de la Cruz Roja Colombiana con especialidad en Telemática Nivel II (CITEL).

## 🚀 Ver el curso en línea
La página web interactiva del curso se puede visitar en:
👉 [https://telematicabolivar2026-afk.github.io/curso-telecomunicaciones-emergencia/](https://telematicabolivar2026-afk.github.io/curso-telecomunicaciones-emergencia/)

## 🛠️ Detalles técnicos
*   **Diseño:** HTML, CSS y JavaScript (basado en el diseño del Curso Nivel 1).
*   **Progreso de los estudiantes:** Firebase Firestore.
*   **Actividades:** H5P.
*   **Evaluaciones:** Google Forms.
*   **Basado en:** Guía para Telecomunicaciones de Emergencia de la IARU Región 2.
